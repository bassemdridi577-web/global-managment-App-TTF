# Tunisie Transformateurs - Labo Management System (Portfolio Demo)

This is a comprehensive Management Information System (MIS) designed for a transformer manufacturing company. It handles production tracking, quality control, inventory management, and technical reporting.

**🚀 This version is a static portfolio demo. All backend services are mocked to allow full feature exploration without a live server.**

## ✨ Key Features

- **📊 Dashboard & Analytics:** Real-time visualization of production status and conformity reports.
- **🔌 Transformer Management:** Complete lifecycle tracking of transformers from manufacturing to final testing.
- **📝 Quality Control (PV d'essais):** Automated generation of test reports (Routine & Type tests) with professional PDF export.
- **📦 Inventory System:** Real-time stock tracking for raw materials (Oil, Copper, Magnetic steel).
- **🏭 Production Line Tracking:** Monitoring of each manufacturing step (Winding, Assembly, Tanking).
- **📅 Planning & Matrix:** Advanced production scheduling and operator activity monitoring.
- **🤖 AI Assistant:** Integrated chat interface for technical guidance and process optimization.
- **💼 Billing & Orders:** Management of client orders and automated invoicing.

## 🛠️ Tech Stack

- **Frontend:** React.js, TypeScript, Three.js (for 3D visualizations), Recharts.
- **Styling:** Vanilla CSS with Glassmorphism and modern UI principles.
- **Mocking:** Custom Axios interceptors for a seamless backend-less experience.
- **Internationalization:** i18next support (French/English/Arabic).

## 🚀 How to Run Locally

1. Clone the repository.
2. Navigate to `laboapp/react-project/app`.
3. Install dependencies: `npm install`.
4. Start the app: `npm start`.

*Note: The app will automatically log you in as an Admin in demo mode.*
